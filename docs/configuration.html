Configuration

Every setting, its default, the file it belongs in, and which one wins. All files are optional: with none, the bot runs on environment variables and the defaults below.

${VAR} in either file is replaced with the environment variable VAR. Keep keys and tokens in the environment, never in a file.

Where the operator config comes from

The first one found is used; the others are ignored:

  1. --config <path>
  2. $CODEREVIEW_CONFIG: a path
  3. $CODEREVIEW_CONFIG_YAML: the YAML itself. The console passes each job's config this way; in CI it can live in one protected variable.
  4. ./codereview.yaml or ./codereview.yml in the working directory, for local use

The environment variable comes before the file in the working directory: in GitLab CI and Bitbucket Pipelines that directory is the PR's checkout, and a codereview.yaml added by a PR must not replace the operator's config. Run codereview config validate to see which source was used and whether it is valid.

Which setting wins

A review setting is resolved from lowest to highest:

  1. built-in defaults
  2. review.defaults in the operator config
  3. the repository's .codereview.yaml
  4. CODEREVIEW_OVERRIDES (per-repository settings from the console)
  5. CLI flags, including turning things off: --approve=false, --score-labels=false, --fail-on none

The operator keeps control of a few things:

  • review.approve and review.commands are operator-only. In .codereview.yaml they are ignored, with a warning in the log.
  • A repository's fail_on can set one where the operator has none, and otherwise only make it stricter.
  • A repository's model is used only with allow_repo_model: true, and only names one of the operator's profiles.
  • instructions, path_instructions, path_filters and learnings add up across levels instead of replacing each other.

CODEREVIEW_OVERRIDES

Per-repository settings as JSON, set by Divmora Code Review Console. They win over the repository's file; CLI flags win over them. Unknown keys are rejected.

CODEREVIEW_OVERRIDES
{"profile": "assertive", "max_comments": 30, "min_severity": "minor",
 "model": "claude", "auto_review": true, "drafts": false,
 "instructions": "added to the repository's",
 "diagram": "auto",
 "labels": {"mode": "suggest", "allow": ["type::*"]},
 "learnings": [{"text": "...", "path": "api/**"}]}
